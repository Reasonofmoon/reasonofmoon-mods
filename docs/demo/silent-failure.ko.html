Silent Failure Detector 나란히 비교 데모

두 터미널은 같은 build.sh를 실행합니다. 240줄을 출력하고 Done in 4.2s ✓로 끝나며 종료 코드도 0이지만, 중간에 실패한 테스트가 한 줄 숨어 있습니다. mod는 오른쪽에만 설치되어 있습니다.

Claude Code에서 보이는 화면을 브라우저에서 흉내 낸 것입니다. 내 컴퓨터에서는 아무것도 실행되지 않습니다.

실행이 끝나면 어느 쪽 로그든 스크롤해서 실패를 직접 찾아보세요. 242줄 중 121번째 줄에 있습니다: [test] auth.spec.ts: 1 failed, 46 passed.

이 데모가 보여주는 것과 보여주지 않는 것

mod는 로그 안의 줄에 색을 칠하지 않습니다. 오른쪽에 보이는 두 가지, 즉 상태줄 경고와 대화창의 경고 한 줄을 더합니다. 또 도구 실행 결과에 메모를 붙여서, Claude가 "완료"라고 말하기 전에 출력을 다시 확인하게 합니다.

기록된 A/B 실험에서는 mod가 없어도 Claude가 이 실패를 찾아냈습니다. 가장 큰 이점은 로그를 읽지 않아도 경고가 바로 보인다는 점이고, Claude가 놓칠 경우를 대비한 이중 확인 역할도 합니다. 자세한 내용은 실행 기록을 보세요.

실제 Claude Code(v2.1.287 이상)에서 써보려면:

claude plugin marketplace add Reasonofmoon/reasonofmoon-mods
claude plugin install silent-failure@reasonofmoon-mods
