Silent Failure Detector: a side-by-side demo

Both terminals run the same build.sh. It prints 240 lines ending in Done in 4.2s ✓ and exits 0, but one failing test is buried in the middle. Only the right side has the mod installed.

This is a browser simulation of what you see in Claude Code. Nothing runs on your machine.

After the run, scroll either log to look for the failure yourself. It's on line 121 of 242: [test] auth.spec.ts: 1 failed, 46 passed.

What this demo does and doesn't claim

The mod doesn't recolor lines in the log. It adds the two things shown on the right: a warning in the status line and one line in the transcript. It also attaches a note to the tool result, so Claude checks the output before calling the step done.

In the recorded A/B runs, Claude also caught this failure without the mod. The main gain is that you see the warning without reading the log, plus a second check in case Claude misses one. See the run log.

Try the real thing in Claude Code (v2.1.287 or later):

claude plugin marketplace add Reasonofmoon/reasonofmoon-mods
claude plugin install silent-failure@reasonofmoon-mods
